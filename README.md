# AQMS-CoffeeGold-GKUB

Capstone monorepo scaffold for AQMS CoffeeGold system.

## Workspace Structure

- apps/backend: Express + TypeScript API service
- apps/web: Next.js web dashboard and display pages
- apps/mobile: React Native (Expo) mobile app
- iot/firmware: PlatformIO firmware scaffold
- packages/shared: Shared constants and utilities

## Quick Start

1. Install dependencies from repo root:
   npm install
2. Start backend dev server:
   npm run dev:backend
3. Start web app:
   npm run dev:web

Mobile and IoT are scaffolded and ready for next implementation phase.
